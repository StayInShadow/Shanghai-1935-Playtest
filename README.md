# Shanghai 1935 - Playtest

[Download the Windows playtest](https://github.com/StayInShadow/Shanghai-1935-Playtest/releases/tag/playtest-2026-10-26).

Under **Assets**, download **Shanghai1935-Windows.zip**. Extract the whole ZIP,
then double-click **Play.cmd** or **Shanghai1935.exe**. Keep runtime-assets beside
the executable. Godot installation is not required.

Choose **TUTORIAL** in the opening menu for controls and practice. Keyboard/mouse,
Xbox and PlayStation prompts are supported. A Compatibility launcher is included
for computers that cannot start the normal Forward+ renderer; lighting can differ.

This is an experimental Windows x64 playtest. The packaged build passes 98
focused resource/startup checks, including the selected melee animation. A full
playthrough, physical controllers and audible mix are not certified by those checks.

Third-party notices are included in the download's Licenses folder.
